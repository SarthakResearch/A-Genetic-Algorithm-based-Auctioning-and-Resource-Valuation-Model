README

This folder contains the Excel workbooks with the numerical results and graphs reported in the research paper:

"A Genetic Algorithm based Auctioning and Resource Valuation Model for Multi Constrained Task Allocation in Heterogeneous Cloud Computing Environments"

Communicated to the Journal of Computers and Electrical Engineering, Elsevier.

These workbooks contain the results exported by Results.java (averaged across the configured number of independent runs) for the experiments described in the paper, and were used to generate the corresponding figures and tables reported in the manuscript.

For details on how these results were generated, refer to the main repository README and the source code (Main.java, GeneticAlgorithm.java, EachRunResult.java, Results.java).

The manuscript is under revision and hence not published yet. As soon as the paper gets published and made available online, the DOI and URL will be updated here. 

For any questions, or details related to the implementation, please open an issue in this repository or you can contact the first author at sarthak@bhu.ac.in.
